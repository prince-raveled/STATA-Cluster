What a tier deliberately leaves out

  • Magnitude. A tier is built from two numbers — how often a taxon was significant and how often the direction agreed. Effect size is not one of them, so a ROBUST taxon can have a difference far too small to care about. Read the effect column beside the tier, never the tier alone.
  • Independence. The analyses behind a tier are re-analyses of the same samples. "Significant in 86%" measures how much the conclusion depends on your choices. It is not a p-value, not a probability, and not 86 replications.
  • Which choice was responsible. The tier says the answer moved, not what moved it. Open a taxon to see that.
  • Causation, and biology. A difference that survives every analytical choice is still an association, and statistical stability is not importance.

Each taxon's page carries the same caveats against its own numbers.

Reading the intervals. Each interval comes from a bootstrap that resamples taxa, and it is printed with the percentage from that same resample — so an interval always brackets the number beside it. The headline percentage is computed differently: on every taxon, with the mixed-effects model. Reading the effect axis. The effect plotted here is computed from the abundance table itself — the log2 ratio of mean relative abundance between your two groups — and not from any model. So it is the same number whichever statistical test produced the point, and it does not move when an analysis adjusts for a covariate. Measured directly on this build, its spread across 32 different covariate-adjustment sets is exactly zero, while the linear model's own coefficient for the same taxon moves with a standard deviation of 0.65.

That is deliberate: one effect scale that every method can be plotted on. But it means this axis cannot show you covariate-driven instability — do not read a flat effect axis as evidence that adjustment does not matter. Where adjustment matters, it shows up in colour, as points changing significance, and in each method's own native statistic in the downloads. Treat the plotted effect as a common yardstick, not as a model coefficient you could quote from a regression table.

Exactly what produced these numbers

Everything needed to reproduce this run is recorded in the run manifest — a single JSON file, also included in the results bundle as manifest.json. It holds:

  • the version of MicroVerse and of every scientific dependency that ran;
  • every random seed, including the rarefaction draws, which are what make the subsampling reproducible rather than merely repeatable;
  • the full grid accounting — enumerated, pruned with reasons, valid, fitted;
  • the dataset's dimensions and a fingerprint of the table itself, so you can confirm a later run used the same input;
  • the attribution diagnostics behind the grade shown above;
  • the validation record each claim on this page is read from.

The same content is available as JSON at /api/jobs/{{ token }}/results under manifest.

There is no “best specification” export here, and there will not be one. The point of a multiverse is the distribution; a tool that hands you your favourite point in it is a p-hacking device. Every export contains the whole distribution.
